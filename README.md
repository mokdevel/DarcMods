# DarcMods
A bunch Arma Reforger mods.

## DarcMissions
<img src="https://github.com/mokdevel/DarcMods/blob/main/DarcMissions/thumbnail.png" width=30% height=30%>
A mod that spawns various types of PVE missions. See [Documentation](./DarcMissions/README.md) for more information and configuration options.

## DarcChopper
<img src="https://github.com/mokdevel/DarcMods/blob/main/DarcChopper/thumbnail.png" width=30% height=30%>
A mod that adds AI flying capabilities to helicopters. See [Documentation](./DarcChopper/README.md) for more information and configuration options.

## DarcDeathMarker
<img src="https://github.com/mokdevel/DarcMods/blob/main/DarcDeathMarker/thumbnail.png" width=30% height=30%>
The mod creates a map marker on the position where you died. The marker is active 10 minutes (by default) and disappears after that. If you die again, another marker replaces the previous one. See [Documentation](./DarcDeathMarker/README.md).

## DarcMissionsCompatFF
<img src="https://github.com/mokdevel/DarcMods/blob/main/DarcMissionsCompatFF/thumbnail.png" width=30% height=30%>
Compatibility mod for Freedom Fighters. See [Documentation](./DarcMissionsCompatFF/README.md). 

## DarcSpawner
<img src="https://github.com/mokdevel/DarcMods/blob/main/DarcSpawner/thumbnail.png" width=30% height=30%>
Spawns containers, vehicles and lootboxex, randomly on map with some loot. See [Documentation](./DarcSpawner/README.md) for configuration.

## DarcCore
<img src="https://github.com/mokdevel/DarcMods/blob/main/DarcCore/thumbnail.png" width=30% height=30%>
The core functions collected under one mod. See: [Documentation](./DarcCore/README.md)
