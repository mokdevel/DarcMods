# GM functionality
The mod some functionality available for GM use. In order for this to work correctly, make sure you have ``admin`` permission in your server conf.

```
	"rcon": {
		"permission": "admin",
	},
```

## Start missions
From the entity browser, you can drop missions to the world. They will be started after a while.

## Map information
Map show information about 
- NonValidAreas
- Missions that are in ACTIVE state.
